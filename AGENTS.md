# Agent Instructions

## Editing

- Work in **read-only mode by default**.
- Do not create, modify, delete, rename, or move files unless the user explicitly asks you to make changes.
- Analysis, review, explanation, debugging, planning, and suggestions do **not** grant permission to edit files.
- When editing is explicitly requested, modify only what is necessary for that request.
- If editing permission is unclear, do not modify files.

## Execution

- Do not run anything unless the user explicitly asks you to.
- Editing permission does **not** imply execution permission.
